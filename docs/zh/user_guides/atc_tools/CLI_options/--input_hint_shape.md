# --input\_hint\_shape

## 产品支持情况

全量芯片支持

## 功能说明

设置动态shape模型输入数据的shape提示信息。

原始模型输入数据的shape不固定（动态shape）时，模型转换阶段无法获取输入的具体shape。通过该参数按输入节点的index指定shape提示信息，模型转换时以该shape作为对应输入的提示shape，参与编译期的shape推导；模型实际执行时，仍按运行期输入的真实shape执行。

## 关联参数

该参数不能与[--dynamic\_batch\_size](--dynamic_batch_size.md)、[--dynamic\_image\_size](--dynamic_image_size.md)、[--dynamic\_dims](--dynamic_dims.md)参数同时使用，同时设置时模型转换报错。

## 参数取值

**参数值：**
输入节点的index与shape提示信息的组合，例如"0:[16,32,208,208];1:[16,3,224,224]"。

**参数值格式：**

- 单个输入的格式为`index:[n,c,h,w]`，其中index为输入节点的序号（从0开始计数），多个输入之间使用英文分号分隔。
- 指定的参数必须放在双引号中。

**参数值约束：**

- shape提示信息需要用英文中括号\[\]包括，各维度的取值为大于等于0的整数。
- shape提示信息的维度个数需要与对应输入的实际维度个数一致，否则该提示信息在编译期不生效。

**参数默认值：**
无。不设置时该功能不生效。

## 推荐配置及收益

无。

## 示例

```bash
atc --input_hint_shape="0:[16,32,208,208];1:[16,3,224,224]" ...
```
