## 功能说明

设置动态 shape 模型输入数据的值提示信息。

原始模型输入数据为动态 shape 时，模型转换阶段无法获取输入的具体值。通过该参数按输入节点的 index 指定值提示信息，模型转换时以该值参与编译期的符号值推导和 guard 生成；模型实际执行时，仍按运行期输入的真实数据执行。

该参数仅参与编译期符号化，不改变运行期输入的 shape 或值；对不支持值符号化或非 host placement 的输入不生效。

## 关联参数

可与 [--input_hint_shape](--input_hint_shape.md) 同时使用，分别提供 shape 提示和值提示。

OM2 模式暂不支持该参数。

## 参数取值

**参数值：**
输入节点的 index 与值提示列表的组合，例如 `"0:[1,2];1:[3,4]"`。

**参数值格式：**

- 单个输入的格式为 `index:[v0,v1,...]`，其中 index 为输入节点的序号（从 0 开始计数），多个输入之间使用英文分号分隔。
- 指定的参数必须放在双引号中。

**参数值约束：**

- 值提示列表需要使用英文中括号 `[]` 包括，各元素的取值为大于等于 0 的整数。
- index 必须为大于等于 0 的整数，且同一参数内不能重复。
- 值提示的元素个数不应超过对应输入 tensor 的元素个数；超过时该提示会被忽略。
- 值提示仅对需要值符号化的 host 输入生效。

**参数默认值：**
无。不设置时该功能不生效。

## 推荐配置及收益

无。

## 示例

```bash
atc --input_hint_shape="0:[2];1:[2]" \
    --input_hint_value="0:[6,3];1:[1,2]" ...
```
