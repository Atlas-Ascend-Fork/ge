# --compress\_weight\_conf

## 产品支持情况

全量芯片支持

## 功能说明

权重压缩配置文件路径以及文件名，通过该参数指定网络中需要进行权重压缩的算子节点，模型转换时对指定节点的权重进行压缩处理，减小生成的om离线模型文件体积。

## 关联参数

使用该参数时，不能同时将[--enable\_compress\_weight](--enable_compress_weight.md)参数设置为true，两者同时设置时模型转换报错。

## 参数取值

**参数值：**
配置文件路径以及文件名。

**参数值格式：**
路径和文件名：支持大小写字母（a-z，A-Z）、数字（0-9）、下划线（\_）、短横线（-）、句点（.）、中文汉字。

**参数值约束：**
配置文件内容为需要进行权重压缩的算子节点名称，多个节点名称之间使用英文分号分隔。若配置的节点在网络中不存在，模型转换时打印告警日志并跳过该节点。

## 推荐配置及收益

无。

## 示例

假设权重压缩配置文件名称为compress\_weight.cfg，文件内容配置示例如下（表示对conv1、conv2两个节点的权重进行压缩）：

```text
conv1;conv2
```

将该文件上传到ATC工具所在服务器，例如上传到$HOME/module，使用示例如下：

```bash
atc --compress_weight_conf=$HOME/module/compress_weight.cfg ...
```
