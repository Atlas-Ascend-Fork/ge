# 环境准备

- 安装固件与CANN软件包：参见[环境准备](env_preparation.md)安装固件与CANN软件包，并设置环境变量。

    CANN软件包提供了GE、acl等的头文件（include/graph、include/register、include/external）。

- 安装PyTorch、TorchNPU和TorchAir：PyTorch场景必需安装，与CANN软件包配套关系请单击[Link](https://www.hiascend.com/document/detail/zh/Pytorch/2610/releasenote/docs/zh/release_notes/release_notes.md)，查看“版本说明 \>相关产品版本配套说明”章节。

    详细安装方法请参见单击[Link](https://www.hiascend.com/document/detail/zh/Pytorch/2610/index/index.html)，查看“安装指南 \> 软件安装 \> 安装TorchNPU”章节，TorchAir作为TorchNPU的三方库，随着TorchNPU包一起安装。
