# 无符号常量列表绕过标量范围检查，负值及越界值被 ctypes 静默回绕

## 行为与根因

uint32/uint64 常量的标量和列表入口保持一致，值不在对应无符号范围时在原生调用前报错；合法边界值逐位保留。

仅 uint32 标量检查完整值域，列表路径直接构建 c_uint 数组；uint64 标量只检查负值，未检查上界。

列表路径在 ctypes 转换前检查无符号值域，并补齐 uint64 标量上界；不改变有符号和浮点常量。

## 验证和边界

回归 `tests/ge/ut/ge/graph/pyge_tests/unsigned_constant_range_cpu_test.py`：12 passed in 0.10s。执行真实 GraphBuilder、TensorHolder、Graph、枚举及 ctypes 缓冲，原生库边界使用替身。未验证 CANN/NPU 或全量 C++ UT/ST。

## 扫描合规整理

四种整数常量的值及形状准备复用同一内部方法，保留标量分派、空列表、类型错误及无符号范围检查的顺序与内容；浮点常量实现不变。类方法按魔法方法、属性、静态方法、类方法、普通方法、受保护实例辅助方法的类别排列；各类别内部保留原有相对顺序。
