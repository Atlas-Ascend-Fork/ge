## Applicable Products

All chips are supported.

## Description

Checks whether the **shape** contains unknown dimensions.

## Prototype

```python
is_unknown_shape() -> bool
```

## Parameters

None

## Return Value

Returns **True** if the **shape** contains dimensions with value -1 or -2; otherwise, returns **False**.

## Constraints

None
