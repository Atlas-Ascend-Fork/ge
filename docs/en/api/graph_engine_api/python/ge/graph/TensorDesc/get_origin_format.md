## Applicable Products

Supported on all chips.

## Description

Obtains the original **Format** of the **Tensor** described by **TensorDesc**.

This **Format** refers to the **Format** of the original network model.

## Prototype

```python
get_origin_format() -> Format
```

## Parameters

None

## Return Value

Returns the **Format** enum value.

## Constraints

None
