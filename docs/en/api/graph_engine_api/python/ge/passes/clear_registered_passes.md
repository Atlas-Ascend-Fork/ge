# clear\_registered\_passes

## Applicable Products

Supported on all chips.

## Description

Clears all registered passes.

## Prototype

```python
clear_registered_passes() -> None
```

## Parameters

None

## Return Value

None

## Constraints

This operation clears the entire Pass registration table. After clearing, all registered passes are no longer available.
