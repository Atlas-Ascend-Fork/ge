## Applicable Products

Supported on all chips.

## Description

Determines whether the current object still holds an unreleased native Pattern.

## Prototype

```python
is_valid() -> bool
```

## Parameters

None

## Return Value

Returns **True** if the native Pattern is still held and not released, and **False** if it has been released.
