# Multi-Stream Planning APIs

The Multi-Stream Planning Interface is provided by the `multistream` package. It is used to build task dependency graphs, set node information, and generate and query stream planning results. The API entries are maintained in [GraphEngine API](../../../README.md).

For the complete usage flow, see [Automatic Multi-Stream Parallelism](../../../../../user_guides/graph_dev/auto_multistream.md).
