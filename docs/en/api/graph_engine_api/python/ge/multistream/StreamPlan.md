# StreamPlan

## Prototype

```python
get_stream_id(node: DAGNode) -> int
get_required_stream_count() -> int
get_core_num(node: DAGNode, kernel_type: str) -> int
```

## Parameters

| Name | Input/Output | Description |
| --- | --- | --- |
| node | Input | The [DAGNode](DAGNode.md) in the original graph for this planning. |
| kernel_type | Input | Resource type. Only the string `"AIC"` or `"AIV"` is accepted. |

## Return Value

| Method | Return Value |
| --- | --- |
| `get_stream_id` | Stream ID of the node. For excluded normal nodes, returns `multistream.INVALID_STREAM_ID` (-1). |
| `get_required_stream_count` | Total stream count of normal streams and additional serial streams, excluding the start offset. |
| `get_core_num` | Returns 0 in the current version, indicating that the caller retains the original core count configuration. |

## Constraints

- The result is generated by [plan](plan.md). Subsequent planning does not overwrite the existing result.
- A `TypeError` is raised when the type of the node or resource type parameter is invalid. A `ValueError` is raised when the node does not belong to the original graph or the resource string is not AIC/AIV.
- Normal stream IDs fall within `[base_stream_id, base_stream_id + max_stream_num)`. Additional serial streams can make the total stream count exceed the upper limit of the normal stream count.
- A stream ID is a planning identifier, not a Runtime stream handle. The caller reserves resources based on the total stream count.

## Examples

Before the call, prepare the CANN Runtime and complete runtime initialization or offline target SoC configuration. For details, see [Constraints of plan](plan.md#constraints).

```python
import multistream as ms

graph = ms.DAGGraph("example")
node = graph.add_node("compute", "Relu")
result = ms.plan(graph, max_stream_num=2)
print(result.get_required_stream_count())
print(result.get_stream_id(node))
assert result.get_core_num(node, "AIV") == 0
```
