# bundle\_build\_model

## Applicable Products

Supported on all chips.

## Description

Compiles a set of input **Graph** objects into an offline model adapted to the AI processor and saves it to a memory buffer. This API is applicable to weight update scenarios.

## Prototype

```python
bundle_build_model(graph_with_options: List[GraphWithOptions]) -> ModelBuffer
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| graph_with_options | Input | A group of graphs to be compiled and their compilation parameters. This input parameter is a structure that includes the following parameters:<br>class GraphWithOptions:<br>   graph: Graph<br>   build_options: Dict[str, str] = field(default_factory=dict)<br>A group of graphs includes the weight initialization graph, the weight update graph, and the inference graph. Among them, only the inference graph supports setting the following **options** parameters.<br>You can configure offline model compilation information by passing the **options** parameter. For the currently supported configuration parameters, see [Configuration Parameters Supported by aclgrphBuildModel](../../../cpp/ge/aclgrphBuildModel_config_params/aclgrphbuildmodel_config_params.md), where the key is the string value corresponding to the C++ constant. |

## Return Value

\(ModelBuffer\) Returns the offline model cache generated by compilation.

## Constraints

- If **graph\_with\_options** is not of the **List\[GraphWithOptions\]** type, a TypeError is thrown.
- If compilation fails, a RuntimeError is thrown.
