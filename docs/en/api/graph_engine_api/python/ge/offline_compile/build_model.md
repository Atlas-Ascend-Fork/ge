# build\_model

## Applicable Products

Supported on all chips.

## Description

Compiles the input **Graph** into an offline model adapted to the AI processor and saves it to a memory buffer.

## Prototype

```python
build_model(graph: Graph, build_options: Optional[dict] = None) -> ModelBuffer
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| graph | Input | **Graph** to be compiled. |
| build_options | Input | Graph-level configuration parameters.<br>Mapping table of the configuration parameter dict, where the key is the parameter type and the value is the parameter value, both in string format, used to describe the offline model compilation configuration information.<br>For the configuration parameters supported in the dict, see [Configuration Parameters Supported by aclgrphBuildModel](../../../cpp/ge/aclgrphBuildModel_config_params/aclgrphbuildmodel_config_params.md), where the key is the string value corresponding to the C++ constant. |

## Return Value

\(ModelBuffer\) Returns the offline model cache generated by compilation.

## Constraints

- If **graph** is not of the **Graph** type, a **TypeError** is thrown.
- If build\_options is not a valid string dict, a **TypeError** is thrown.
- If compilation fails, a **RuntimeError** is thrown.

- **For duplicate options compilation configuration parameters in build\_model and build\_initialize, it is recommended not to configure them repeatedly. If they are configured repeatedly, the values passed in build\_model take precedence.**
- When using the **build\_model** API to pass the **build\_options** parameter, in a multi-graph scenario, if the passed parameter is **PRECISION\_MODE** or **PRECISION\_MODE\_V2**, the parameter values set for multiple graphs must be the same.
- The offline model compiled using the **build\_model** API is stored in the memory buffer:
  - To save the model in the memory buffer as an offline model file xx.om, call the **save\_model** API to serialize and save the offline model to a file. For subsequent inference, use the API that loads the model **from a file**, such as **aclmdlLoadFromFile**, and then use the **aclmdlExecute** API to perform inference.
  - If the offline model is stored in the memory buffer: for subsequent inference, use the API that loads the model **from memory**, such as **aclmdlLoadFromMem**, and then use the **aclmdlExecute** API to perform inference.

For details about the APIs, see [Model Management](https://gitcode.com/cann/docs/blob/9.2.0/docs/zh/app-dev/c/00_acl_cpp_dev.md).
