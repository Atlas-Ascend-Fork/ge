## Applicable Products

Supported on all chips.

## Description

Releases the memory of the specified **MemBlock** back to the memory pool.

## Prototype

```python
free(block: MemBlock) -> None
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| **block** | Input | Memory **block** object. |

## Return Value

None

## Constraints

Abstract method, users must implement it.
