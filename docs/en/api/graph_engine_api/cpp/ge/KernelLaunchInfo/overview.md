The **KernelLaunchInfo** class provides developers with APIs for creating and managing tasks delivered to the device, allowing developers to set or obtain the Launch information of the current task to be delivered to the device.

This class supports users in creating a new Launch task or modifying a Launch task already generated by the framework.

## Header File to Include

```c++
#include <graph/kernel_launch_info.h>
```
