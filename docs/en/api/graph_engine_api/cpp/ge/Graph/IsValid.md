## Applicable Products

Supported on all chips.

## Header File/Library File

- Header file: \#include <graph/graph.h\>
- Library file: libgraph.so

## Description

Determines whether the **Graph** object is valid, that is, whether it can be executed.

## Prototype

```c++
bool IsValid() const
```

## Parameters

None

## Return Value

| Parameter | Type | Description |
| --- | --- | --- |
| - | bool | - **True**: The constructed **Graph** object is valid and can be executed.<br>  - **False**: The constructed **Graph** object is invalid and cannot be executed. |

## Constraints

None
