# aclgrphBundleSaveModel

<!-- md-trans-meta sourceCommit=1dea726c9fa59e3b81454a7fd0930f2a4914fdd3 translatedAt=2026-10-16T11:04:47.852Z pushedAt=2026-10-28T07:40:22.110Z nl=2 -->

## Applicable Products

Supported on all chips.

## Header File/Library File

- Header file: \#include <ge/ge\_ir\_build.h\>
- Library file: libge\_compiler.so

## Description

Serializes the offline model and saves it to a specified file.

- Unlike the [aclgrphSaveModel](aclgrphSaveModel.md) API, this API applies to weight update scenarios. A model generated by this API must be loaded through the [aclmdlBundleLoadFromFile](../../c/acl/aclmdlBundleLoadFromFile.md) or [aclmdlBundleLoadFromMem](../../c/acl/aclmdlBundleLoadFromMem.md) API to perform inference with ACL.
- The **aclgrphBundleSaveModel** API can be used to persist the model to disk only after the offline model cache is generated by the [aclgrphBundleBuildModel](aclgrphBundleBuildModel.md) API.

## Prototype

```c++
graphStatus aclgrphBundleSaveModel(const char_t *output_file, const ModelBufferData &model)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| model | Input | Offline model buffer data generated by **aclgrphBundleBuildModel**. For details, see [ModelBufferData](ModelBufferData.md).<br>**data** points to the generated model data, and **length** indicates the actual size of the model. |
| output_file | Input | Name of the file to which the offline model is saved. The generated offline model file name automatically ends with the .om suffix, for example, **ir_build_sample.om** or<br>**ir_build_sample_linux_x86_64.om**. If the om file name contains the operating system and architecture, the om file can be used only in the running environment with that operating system and architecture. |

## Return Value

| Parameter | Type | Description |
| --- | --- | --- |
| - | graphStatus | GRAPH_SUCCESS(0): Success.<br>Other values: Failure. |

## Constraints

If the generated om model file name contains the operating system and architecture, but the operating system and its architecture are inconsistent with the model running environment, use the file name together with the **OPTION\_HOST\_ENV\_OS** and **OPTION\_HOST\_ENV\_CPU** parameters to set the operating system type and architecture of the model running environment. For details about the parameters, see [Configuration Parameters Supported by aclgrphBuildInitialize](./aclgrphBuildInitialize_config_params/basic_functions.md).

## Examples

```c++
// Header file to include:
#include "ge_ir_build.h"
#include "ge_api_types.h"

// 1. Generate the graph.
Graph origin_graph("Irorigin_graph");
GenGraph(origin_graph);

// 2. After the graph is created, call aclgrphBuildInitialize to initialize the system and allocate resources.
std::map<AscendString, AscendString> global_options;
auto status = aclgrphBuildInitialize(global_options);

// 3. Generate a graph whose weights can be updated, which consists of three parts: the weight initialization graph, the weight update graph, and the inference graph.
// Weight initialization is optional. Determine whether to include the weight initialization graph based on the business scenario. If it is not included, the Device memory required for model loading can be saved.
WeightRefreshableGraphs weight_refreshable_graphs;
std::vector<AscendString> const_names;
const_names.emplace_back(AscendString("const_1"));
const_names.emplace_back(AscendString("const_2"));
status = aclgrphConvertToWeightRefreshableGraphs(origin_graph, const_names, weight_refreshable_graphs);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphConvertToWeightRefreshableGraphs failed!" << endl;
    aclgrphBuildFinalize();
    return -1;
}

// 4. Compile the graph whose weights can be updated into an offline model and save it in a memory buffer.
std::map<AscendString, AscendString> options;
std::vector<ge::GraphWithOptions> graph_and_options;
// Inference graph.
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.infer_graph, options});
// Weight initialization graph.
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.var_init_graph, options});
// Weight update graph.
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.var_update_graph, options});
ge::ModelBufferData model;
status = aclgrphBundleBuildModel(graph_and_options, model);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphBundleBuildModel failed" << endl;
    aclgrphBuildFinalize();
    return -1;
}

// 5. Save the model in the memory buffer as an offline model file.
const char *file="./xxx" ;
status = aclgrphBundleSaveModel(file, model);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphBundleSaveModel failed" << endl;
    aclgrphBuildFinalize();
    return -1;
}
// 6. The graph construction process ends. Release resources.
aclgrphBuildFinalize();
```
