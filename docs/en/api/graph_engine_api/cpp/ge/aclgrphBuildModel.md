# aclgrphBuildModel

## Applicable Products

Supported on all chips.

## Header File/Library File

- Header file: \#include <ge/ge\_ir\_build.h\>
- Library file: libge\_compiler.so

## Description

Compiles the input **Graph** into an offline model adapted to the AI processor and saves it to a memory buffer.

## Prototype

> [!NOTE]
> The string-type API will be deprecated in future versions. You are advised to use the non-string type instead.

```c++
graphStatus aclgrphBuildModel(const ge::Graph &graph, const std::map<std::string, std::string> &build_options, ModelBufferData &model)
graphStatus aclgrphBuildModel(const ge::Graph &graph, const std::map<AscendString, AscendString> &build_options, ModelBufferData &model)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| graph | Input | **Graph** to be compiled. |
| build_options | Input | Graph-level configuration parameters.<br>Mapping table of the configuration parameter map, where the key is the parameter type and the value is the parameter value, both in string format, used to describe the offline model compilation configuration.<br>For the configuration parameters in the map, see [Configuration Parameters Supported by aclgrphBuildModel](./aclgrphBuildModel_config_params/aclgrphbuildmodel_config_params.md). |
| model | Output | Offline model cache generated by compilation. The model is saved in the memory buffer. For details, see [ModelBufferData](ModelBufferData.md).<br>**data** points to the generated model data, and **length** indicates the actual size of the model. |

## Return Value

| Parameter | Type | Description |
| --- | --- | --- |
| - | graphStatus | GRAPH_SUCCESS(0): Success.<br>Other values: Failure. |

## Constraints

- **For the duplicate compilation configuration parameters in aclgrphBuildModel and aclgrphBuildInitialize, you are advised not to configure them repeatedly. If they are configured repeatedly, the values passed to aclgrphBuildModel prevail**.
- When the build\_options parameter is passed to the aclgrphBuildModel API, in the multi-graph scenario, if the passed parameter is **ge::ir\_option::PRECISION\_MODE** or **ge::ir\_option::PRECISION\_MODE\_V2**, the parameter values set for multiple graphs must be the same.
- The offline model compiled by the **aclgrphBuildModel** API is saved in the memory buffer:

  - To save the model in the memory buffer as an offline model file xx.om, call the [aclgrphSaveModel](aclgrphSaveModel.md) API to serialize and save the offline model to a file. For subsequent inference, use the API that loads the model **from a file**, such as **aclmdlLoadFromFile**, and then use the **aclmdlExecute** API to perform inference.
  - If the offline model is stored in the memory buffer:

    For subsequent inference, use the API that loads the model **from memory**, such as aclmdlLoadFromMem, and then use the aclmdlExecute API to perform inference.

    For details about how to use the APIs, see the "Model Inference" section in *[Application Development](https://gitcode.com/cann/docs/blob/9.2.0/docs/zh/app-dev/c/00_acl_cpp_dev.md)*.
