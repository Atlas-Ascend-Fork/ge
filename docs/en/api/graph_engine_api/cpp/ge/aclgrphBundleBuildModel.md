# aclgrphBundleBuildModel

## Applicable Products

Supported on all chips.

## Header File/Library File

- Header file: \#include <ge/ge\_ir\_build.h\>
- Library file: libge\_compiler.so

## Description

Compiles a group of input graphs into an offline model adapted to the AI processor.

The difference from the [aclgrphBuildModel](aclgrphBuildModel.md) API is that this API applies to weight update scenarios. After the offline model cache is generated through the **aclgrphBundleBuildModel** API, use the [aclgrphBundleSaveModel](aclgrphBundleSaveModel.md) API to persist it to disk.

## Prototype

```c++
graphStatus aclgrphBundleBuildModel(const std::vector<ge::GraphWithOptions> &graph_with_options, ModelBufferData &model)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| graph_with_options | Input | A group of graphs to be compiled and the compilation parameters. This input parameter is a structure. For the parameters it contains, see the **GraphWithOptions** structure below.<br>A group of graphs includes the weight initialization graph, the weight update graph, and the inference graph. Only the inference graph supports setting the following **options** parameters.<br>You can configure offline model compilation information by passing the **options** parameter. For the currently supported configuration parameters, see [Configuration Parameters Supported by aclgrphBuildModel](./aclgrphBuildModel_config_params/aclgrphbuildmodel_config_params.md). |
| model | Output | The offline model cache generated by compilation. For details, see [ModelBufferData](ModelBufferData.md).<br>**data** points to the generated model data, and **length** indicates the actual size of the model. |

```c++
struct GraphWithOptions {
  ge::Graph graph;
  std::map<AscendString, AscendString> build_options;
};
```

## Return Value

| Parameter | Type | Description |
| --- | --- | --- |
| - | graphStatus | **GRAPH_SUCCESS(0)**: Success.<br>Other values: Failure. |

## Constraints

If multiple graphs in this API involve shared variable operators with the same name, the API performs accelerated fusion of the variable operators internally. It is recommended to generate them through the [aclgrphConvertToWeightRefreshableGraphs](aclgrphConvertToWeightRefreshableGraphs.md) API; otherwise, format inconsistency of the variable operators may occur.
