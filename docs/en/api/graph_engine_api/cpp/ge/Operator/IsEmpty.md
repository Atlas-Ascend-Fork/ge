## Applicable Products

Supported on all chips.

## Header File and Library File

- Header file: \#include <graph/operator.h\>
- Library file: libgraph.so

## Description

Checks whether the operator object is empty. An empty object is unavailable.

## Prototype

```c++
bool IsEmpty() const
```

## Parameters

None

## Return Value

- True: The object is empty.
- False: The object is not empty.

## Constraints

None
