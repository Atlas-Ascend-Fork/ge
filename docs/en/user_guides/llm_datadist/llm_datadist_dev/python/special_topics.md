## KV Cache Swapping

**Feature Overview**

KV Cache swapping refers to swapping KV Cache out from the Device to the Host, or swapping it in from the Host to the Device.

In PA scenarios, because the capacity of the KV Cache is limited, the KV Cache required by a task must be swapped in and out dynamically based on factors such as task priority and execution status, so as to improve memory utilization.

**Involved APIs**

|Interface Name|Description|
|--|--|
|CacheManager.swap_blocks|In the CacheManager scenario, swaps the KV memory on the corresponding block_index in or out|
|KvCacheManager.swap_blocks|In the KvCacheManager scenario, swaps the KV memory on the corresponding block_index in or out|

**Example**

```python
from llm_datadist import KVCache
...
npu_cache = kv_cache_manager.allocate_blocks_cache(npu_cache_desc, npu_cache_key)
cpu_cache = KvCache.create_cpu_cache(cpu_cache_desc, cpu_addrs) # cpu_addrs comes from the created CPU tensors
# swap in
kv_cache_manager.swap_blocks(cpu_cache, npu_cache, {1:2, 3:4})
# swap out
kv_cache_manager.swap_blocks(npu_cache, cpu_cache, {1:2, 3:4})
```

## Common Prefix

**Feature Overview**

A common prefix refers to the identical starting portion shared by multiple input prompts during a single inference process.

It can be used to copy the KV Cache memory generated by the common prefix to the KV Cache of a new user request for inference.

**Involved Interfaces**

|Interface Name|Description|
|--|--|
|CacheManager.copy_cache|Copies the cache in the CacheManager scenario.|
|KvCacheManager.copy_cache|Copies the cache in the KvCacheManager scenario.|

**Function Example**

```python
src_cache = kv_cache_manager.allocate_cache(npu_cache_desc, npu_cache_key) # Prefix cache
dst_cache = kv_cache_manager.allocate_cache(npu_cache_desc, npu_cache_key) # New request cache

kv_cache_manager.copy_cache(dst_cache, src_cache, dst_batch_index, src_batch_index, offset, size)
```
