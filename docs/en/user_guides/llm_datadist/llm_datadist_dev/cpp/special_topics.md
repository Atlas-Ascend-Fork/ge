## Role Switching

**Scenarios**

This feature is mainly used in scenarios where the number of PD cluster nodes is fixed. When business requirements change, PD cluster nodes are expected to switch roles among themselves to improve resource utilization.

**Involved APIs**

Call the SetRole API to switch the role of LLM-DataDist.

**Feature Example**

The example switches the role from Decoder to Prompt. After the role switch, call other LLM-DataDist APIs based on the business feature.

1. During LLM-DataDist initialization, set OPTION\_ENABLE\_SET\_ROLE to "1".

    ```python
    LlmDataDist llm_data_dist(DECODER_CLUSTER_ID, LlmRole::kDecoder);
    std::map<AscendString, AscendString> options;
    options[OPTION_DEVICE_ID] = "0";
    options[OPTION_BUF_POOL_CFG] = R"({
    "buf_pool_size": 2147483648
    })";
    options[OPTION_ENABLE_SET_ROLE] = "1";
    auto ret = llm_data_dist.Initialize(options);
    if (ret != LLM_SUCCESS) {
        printf("[ERROR] Initialize failed, ret = %u\n", ret);
        return -1;
    }
    ```

2. Call SetRole to switch the role.

    ```python
    std::map<AscendString, AscendString> options;
    // Replace with the real IP and port.
    options[OPTION_LISTEN_IP_INFO] = "ip:port";
    llmDataDist.SetRole(LlmRole::kPrompt, options);
    ```

## Common Prefix

**Scenarios**

A common prefix refers to the identical starting portion shared by multiple inputs of model inference.

This feature can be used to copy the KV cache memory generated by the common prefix computation to the KV cache of a new user request for inference.

**Involved APIs**

|Interface Name|Feature|
|--|--|
|CopyKvCache|Copies the KV cache.|

**Feature Example**

```python
ret = llmDataDist.CopyKvCache(src_cache, dst_cache, 0, 0);
if (ret != LLM_SUCCESS) {
    printf("[ERROR] CopyKvCache failed, ret = %u\n", ret);
    return -1;
}
```

**Exception Handling**

For exception handling, see the error codes.
