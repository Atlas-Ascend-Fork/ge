# --output

## Product Support

Supported on all chips.

## Function Description

- For a network model of an open-source framework:

    Path and file name for storing the converted offline model, for example: *$HOME/module/out/tf\_resnet50*. The converted model file is named as specified and automatically ends with the .om suffix, for example: *tf\_resnet50.om* or *tf\_resnet50\_<os\>\_<arch\>.om*. If the .om file name contains the operating system and architecture, the file can be used only in the operating environment of that operating system and architecture.

- For a single-operator description file (JSON format):

    Path for storing the converted single-operator model, for example: *$HOME/singleop/out/op\_model*. By default, the converted model file is named as follows: sequence number \_ operator type \_ input description \(dataType\_format\_shape\)\_ output description \(dataType\_format\_shape\). If the default naming rule is not used, you can specify the model file name through the name attribute in the single-operator description file.

## Related Parameters

- If the name of the .om offline model generated by the atc command contains the OS and architecture, but the OS and architecture are inconsistent with the model operating environment, use this parameter together with [--host\_env\_os](--host_env_os.md) and [--host\_env\_cpu](--host_env_cpu.md) to set the OS type and architecture of the model operating environment.

## Parameter Value

**Parameter value:**

- For a network model of an open-source framework: the path and file name for storing the converted offline model.
- For a single-operator description file (JSON format): the path for storing the converted single-operator model.

**Parameter value format:**
Path and file name: supports uppercase and lowercase letters (a-z, A-Z), digits (0-9), underscores (\_), hyphens (-), periods (.), and Chinese characters.

## Recommended Configuration and Benefits

None.

## Example

- Caffe framework network model:

    ```bash
    atc --output=$HOME/module/out/caffe_resnet50 ...
    ```

- TF framework network model:

    ```bash
    atc --output=$HOME/module/out/tf_resnet50 ...
    ```

- ONNX network model:

    ```bash
    atc --output=$HOME/module/out/onnx_resnet50 ...
    ```

- Single-operator description file:

    ```bash
    atc --output=$HOME/singleop/out/op_model ...
    ```

## Dependencies and Constraints

None.
