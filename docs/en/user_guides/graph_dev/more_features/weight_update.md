# Weight Update

<!-- md-trans-meta sourceCommit=bd3de52c8a808742e9c01b524792105f46cad44c translatedAt=2026-10-21T10:03:11.614Z pushedAt=2026-10-28T08:42:07.409Z nl=2 -->

For weight update scenarios, to allow users to dynamically update weights during the model execution phase after compiling the model once, the APIs provided in this section can be used to implement this function.

## Feature Overview

The main APIs involved in compiling a graph with updatable weights into an offline model are as follows:

![Illustration](../figures/feature_intro_11.png)

1. After the graph is defined, call [aclgrphBuildInitialize](../../../api/graph_engine_api/cpp/ge/aclgrphBuildInitialize.md) to initialize the system and apply for system resources.
2. Call [aclgrphConvertToWeightRefreshableGraphs](../../../api/graph_engine_api/cpp/ge/aclgrphConvertToWeightRefreshableGraphs.md) to generate graphs with updatable weights, which consist of three parts: the weight initialization graph, the weight update graph, and the inference graph.
3. Call [aclgrphBundleBuildModel](../../../api/graph_engine_api/cpp/ge/aclgrphBuildModel.md) to compile the graph with updatable weights into an offline model adapted to the AI processor. During compilation, the built-in operator library and custom operator library are loaded. At this point, the model is stored in a memory buffer.
4. To save the model in the memory buffer as an offline model file xx.om, call [aclgrphBundleSaveModel](../../../api/graph_engine_api/cpp/ge/aclgrphBundleSaveModel.md) to serialize and save the offline model to a file.
5. Call [aclgrphBuildFinalize](../../../api/graph_engine_api/cpp/ge/aclgrphBuildFinalize.md) to end the process and release system resources.

Currently, the model compilation and model file saving APIs can be called consecutively within a single process to compile and save multiple offline models.

## Usage Guide

```c++
// Header files to include:
#include "ge_ir_build.h"
#include "ge_api_types.h"

// 1. Generate a graph.
Graph origin_graph("Irorigin_graph");
GenGraph(origin_graph);

// 2. After the graph is created, call aclgrphBuildInitialize to initialize the system and apply for resources.
std::map<AscendString, AscendString> global_options;
auto status = aclgrphBuildInitialize(global_options);

// 3. Generate weight-updatable graphs, which consist of three parts: weight initialization graph, weight update graph, and inference graph.
// Weight initialization is optional. Determine whether to include the weight initialization graph based on the service scenario. If it is not included, the Device memory required for model loading can be saved.
WeightRefreshableGraphs weight_refreshable_graphs;
std::vector<AscendString> const_names;
const_names.emplace_back(AscendString("const_1"));
const_names.emplace_back(AscendString("const_2"));
status = aclgrphConvertToWeightRefreshableGraphs(origin_graph, const_names, weight_refreshable_graphs);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphConvertToWeightRefreshableGraphs failed!" << endl;
    aclgrphBuildFinalize();
    return -1;
}

// 4. Compile the weight-updatable graphs into an offline model and save it in the memory buffer.
std::map<AscendString, AscendString> options;
std::vector<ge::GraphWithOptions> graph_and_options;
// Inference graph
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.infer_graph, options});
// Weight initialization graph
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.var_init_graph, options});
// Weight update graph
graph_and_options.push_back(GraphWithOptions{weight_refreshable_graphs.var_update_graph, options});
ge::ModelBufferData model;
status = aclgrphBundleBuildModel(graph_and_options, model);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphBundleBuildModel failed" << endl;
    aclgrphBuildFinalize();
    return -1;
}

// 5. Save the model in the memory buffer as an offline model file.
const char *file="./xxx" ;
status = aclgrphBundleSaveModel(file, model);
if (status != GRAPH_SUCCESS) {
    cout << "aclgrphBundleSaveModel failed" << endl;
    aclgrphBuildFinalize();
    return -1;
}
// 6. The graph building process ends. Release resources.
aclgrphBuildFinalize();
```

## Next Steps

To perform inference with the offline model generated by compiling the weight-updated graph, you must load the model by calling aclmdlBundleLoadFromFile or aclmdlBundleLoadFromMem, and then execute inference by calling aclmdlExecute. For details, see the "Model Inference \> Weight Update" section in [Application Development](https://gitcode.com/cann/docs/blob/9.2.0/docs/zh/app-dev/c/00_acl_cpp_dev.md).
