## Feature Overview

The overall process of building a graph through ES consists of the following four steps:

![](../figures/cann_architecture_6.png)

Where:

1. Create a graph builder: Initialize a graph builder instance to provide the context, workspace, and build-related methods required for graph construction.
2. Add start nodes: Start nodes refer to nodes without input dependencies, typically including graph inputs (such as Data nodes) and weight constants (such as Const nodes).
3. Add intermediate nodes: Intermediate nodes are compute nodes with input dependencies, typically generated by the user's graph construction logic and connected using existing nodes as inputs.
4. Set graph outputs: Specify the output nodes of the graph, which serve as the endpoints of the computation results.

During graph construction, two objects are mainly involved. Taking C++ as an example:

- [Graph](../../../api/graph_engine_api/cpp/ge/Graph/overview.md): Represents the final constructed compute graph and is the **target** product of graph construction.
- [EsGraphBuilder](../../../api/graph_engine_api/cpp/ge/es/EsGraphBuilder/overview.md): A graph construction helper class that provides methods for adding nodes, connecting nodes, and setting attributes, and records the intermediate state during graph construction. EsGraphBuilder exists only during the graph construction phase, carries intermediate construction information, and is the object directly operated by the APP during graph construction. After graph construction is complete, its internal state is encapsulated into a Graph instance and returned, and EsGraphBuilder itself and its related resources are released.

## Building a Graph Instance

The following are examples of implementing ES graph construction in C, C++, and Python, using a "two-input summation" computation graph as an example:

- **C code example**:

    ```c
    #include "es_math_ops_c.h"                        // Aggregated header file where the Add operator resides. It contains the header file collection of all operators and the header files of basic structures such as the graph builder.
    // 1. Create a graph builder (EsCGraphBuilder)
    EsCGraphBuilder *builder = EsCreateGraphBuilder("graph_name");
    // 2. Add the start node
    EsCTensorHolder *data0 = EsCreateGraphInput(builder, 0); // Add the first input node
    EsCTensorHolder *data1 = EsCreateInput(builder, 1); // Add the second input node
    // 3. Add the intermediate node
    EsCTensorHolder *add = EsAdd(data0, data1);        // Add the addition computation node (no longer need to explicitly pass the builder)
    // 4. Set the graph output
    EsSetOutput(add, 0);                                // Set the add node as the first output of the graph
    // 5. Complete the graph construction and return the final graph object
    EsGraph *graph = EsBuildGraphAndReset(builder); // Obtain the constructed graph
    // 6. Release the builder and the process resources it manages
    EsDestroyGraphBuilder(builder);
    ```

    For details about the related APIs, see [ES Interface](../../../api/graph_engine_api/cpp/ge/es/es_interface.md).

- **CPP code example**:

    ```c++
    #include "es_math_ops.h"                            // Aggregated header file where the Add operator resides, containing the header file collection of all operators and the header files of basic structures such as the graph builder
    namespace ge {
    namespace es {
    // 1. Create a graph builder (EsGraphBuilder)
    EsGraphBuilder builder("graph_name");
    // 2. Add two input nodes
    std::vector<EsTensorHolder> inputs = builder.CreateInputs<2>();
    EsTensorHolder data0 = inputs[0];
    EsTensorHolder data1 = inputs[1];
    // 3. Add intermediate nodes. In C++, common operators such as addition, subtraction, multiplication, and division are overloaded and can be used directly.
    EsTensorHolder add = data0 + data1;
    // 4. Set the graph output.
    builder.SetOutput(add, 0);
    // 5. Complete graph construction and obtain the constructed Graph object. The resources in the builder are destroyed along with its destructor.
    std::unique_ptr<ge::Graph> graph = builder.BuildAndReset();
    }
    }
    ```

    For details about the related APIs, see [ES Interface](../../../api/graph_engine_api/cpp/ge/es/es_interface.md).

- **Python code example:**

    Before constructing a graph with Python code, install the whl package generated in [(Optional) Generating ES Graph Construction APIs](generate_es_graph_api_optional.md). The installation example is as follows:

    ```bash
    pip3 install {OUTPUT_PATH}/whl/es_math-1.0.0-py3-none-any.whl
    ```

    The graph construction example code is as follows:

    ```python
    from ge.es import GraphBuilder
    from ge.es.math import Add
    # 1. Create a graph builder (EsBuilder).
    builder = GraphBuilder("graph_name")
    # 2. Add two input nodes.
    data0, data1 = builder.create_inputs(2)
    # 3. Add intermediate nodes. In Python, common operators such as addition, subtraction, multiplication, and division are overloaded and can be used directly.
    add = data0 + data1
    # 4. Set the graph output.
    builder.set_output(add, 0)
    # 5. Complete graph construction and return the final graph object.
    graph = builder.build_and_reset()
    ```

    For details about related APIs, see [ES Interface](../../../api/graph_engine_api/cpp/ge/es/es_interface.md).
