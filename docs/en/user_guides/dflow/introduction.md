DataFlow organizes one or more compute processing points into a complete compute flow in a data-driven manner. Through the DataFlow API, compute graphs can be built, modified, compiled, and executed.

This document supports the following products:

- Atlas A3 products
- Atlas A2 series products

This document provides development guides in both C++ and Python to help developers use the DataFlow API for asynchronous pipeline application development, or to refactor existing applications into asynchronous pipelines, thereby achieving high throughput and high concurrency. By reading this document, you can achieve the following goals:

- Understand the basic concepts and scenarios of DataFlow.
- Understand the basic process and implementation methods of application development through the DataFlow API.
- Be able to extend the samples in this document to develop other applications.
