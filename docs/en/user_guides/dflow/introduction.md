DataFlow organizes one or more computation processing points into a complete computation flow in a data-driven manner. Through the DataFlow APIs, you can build, modify, compile, and execute computation graphs.

This document supports the following products:

- Atlas A3 products
- Atlas A2 products

This document provides development guides in both C++ and Python to help developers use the DataFlow APIs to develop asynchronous pipeline applications, or to refactor existing applications into asynchronous pipelines to achieve high throughput and high concurrency. By reading this document, you will be able to achieve the following goals:

- Understand the basic concepts and application scenarios of DataFlow.
- Understand the basic process and implementation methods for developing applications using the DataFlow APIs.
- Extend the samples in this document to develop other applications.
