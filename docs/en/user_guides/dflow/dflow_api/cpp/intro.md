# Overview

The DataFlow interface is used to describe how one or more computation processing points (ProcessPoint) are organized into a complete computation flow in a data-driven manner through data queues. It implements the construction, modification, compilation, and execution of computation graphs.

The DataFlow interface is used for developing custom processing functions, which are executed on the CPU through DataFlow graph construction.
