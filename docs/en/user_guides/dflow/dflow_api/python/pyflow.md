## Function

Supports running a function as a pipeline task locally or remotely. To do so, decorate the function with @pyflow to indicate that the function needs to be run in pipeline mode. When a user class or function is decorated with @pyflow, the fnode graph construction method is automatically added. For usage, see [Examples](#examples).

## Prototype

```python
Decorator @pyflow
```

## Parameters

| Parameter | Data Type | Value Description |
| --- | --- | --- |
| num_returns | int | Indicates the number of outputs of the function when the decorator decorates the function. If this parameter is not set, the function returns one return value by default. Choose either this parameter or the type annotations approach to specify the number and types of function return values. |
| resources | dict | Indicates the resource information required by the current func. Supports memory, num_cpus, and num_npus. The unit of memory is M; num_npus indicates the number of NPU resources required. It is a reserved parameter and currently supports only 1. For example: {"memory": 100, "num_cpus": 1, "num_npus": 1} |
| stream_input | str | Indicates that the input of the current func is a stream input (that is, the function input parameter is a queue). Currently only the "Queue" type is supported. Users can retrieve data from the input queue by themselves. |
| choice_output | function | Indicates that the current func has optional outputs. Only outputs that meet the condition (a user-defined function) are returned. For example:<br>choice_output=lambda e: e is not None<br>This example indicates that only non-None outputs are returned. |
| visible_device_enable | bool | When enabled, the UDF process automatically sets ASCEND_RT_VISIBLE_DEVICES based on the num_npus resource configured by the user, and calls the get_running_device_id API to obtain the corresponding logical ID. Currently num_npus supports only 1, so get_running_device_id returns 0 in this scenario. |
| env_hook_func | function | This hook function allows users to extend the necessary Python environment preparation or import operations before Python UDF initialization.<br>The hook function supports only the no-input and no-output type. |

## Return Value

The decorated class or function.

In exceptional cases, a DfException is thrown. You can catch the exception to obtain the error\_code and message in DfException to view the specific error code and error information. For details, see [DataFlow Error Codes](dataflow-error-code.md).

## Examples

```python
# current is udf.py
import dataflow as df
@df.pyflow(num_returns=2, resources={"memory": 100, "num_cpus": 1})
def func1(a, b):
    return a + b,a - b

@df.pyflow
def func2(a, b):
    return a + b

@df.pyflow(stream_input='Queue')
def func3(a, b):
    data1 = a.get()
    data2 = a.get()
    data3 = b.get()
    return data1 + data2 + data3

@df.pyflow(choice_output=lambda e: e is not None)
def func4(self, a) -> Tuple[int, int]:
    return None, a  # Pass non-None values to corresponding outputs based on the lambda function

# current is graph.py
from UDF import func2
import dataflow as df

# Build the graph
# Define the input
data0 = df.FlowData()
data1 = df.FlowData()
# Build the graph using the fnode method automatically generated by func2
func_out = func2.fnode()(data0, data1)

# Build FlowGraph
dag = df.FlowGraph([func_out])
```

## Constraints

The environment must have the cloudpickle package installed that matches the Python version.

In stream input scenarios, the DataFlow framework does not support data alignment or exception transaction handling.
