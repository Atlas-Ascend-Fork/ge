The DataFlow API describes how to organize one or more processing points (ProcessPoint) into a complete computation flow in a data-driven manner using data queues. It implements the build, modification, compilation, and execution of computation graphs.

The DataFlow API is used for developing custom processing functions, which are executed on the CPU through DataFlow graph construction.
