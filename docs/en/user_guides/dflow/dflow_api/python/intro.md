The DataFlow API is used to describe how one or more computation process points (ProcessPoint) are organized into a complete computation flow in a data-driven manner through data queues. It implements the construction, modification, compilation, and execution of a computation graph.

The DataFlow API is used to develop custom processing functions, which are executed on the CPU by constructing a graph through DataFlow.
