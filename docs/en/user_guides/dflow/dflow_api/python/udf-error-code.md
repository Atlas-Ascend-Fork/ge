For details about the logs involved in the error codes, see *[Log Reference](https://gitcode.com/cann/runtime/blob/9.2.0/docs/zh/log_ref/README.md)*.

## flowfunc

flow\_func\_defines.h provides the flowfunc error codes for users, which are mainly used to determine and handle abnormal logic. The meaning of each error code is as follows.

| Return Code | Description | Solution |
| --- | --- | --- |
| FLOW_FUNC_SUCCESS = 0 | Execution succeeded | Not involved |
| FLOW_FUNC_ERR_PARAM_INVALID = 164000 | Invalid parameter validation | This error code is returned when parameter validation fails, including but not limited to input parameters exceeding the system-supported range and mismatched parameters during the process. When this error code is returned, the log prints the abnormal parameters and the cause of the exception. Locate the cause based on the specific logs. |
| FLOW_FUNC_ERR_ATTR_NOT_EXITS = 164001 | The attribute does not exist when obtaining it | Check the name of the attribute to be obtained, and confirm whether the attribute was set before it is obtained. |
| FLOW_FUNC_ERR_ATTR_TYPE_MISMATCH = 164002 | The attribute type does not match when obtaining it | Check whether the attribute value type corresponding to the attribute name in the input parameter when calling the GetAttr API is consistent with the data type of the output parameter variable. The error log corresponding to this error code prints the actual data type of the attribute corresponding to the attribute name. |
| FLOW_FUNC_FAILED = 564000 | Internal UDF error code | Troubleshoot the issue based on the logs, or contact an engineer for handling (after obtaining the logs, click [Support](https://www.hiascend.com/support) to contact technical support).|
| FLOW_FUNC_ERR_DATA_ALIGN_FAILED = 364000 | Data alignment failed | Possible causes are as follows:<br><br>  - The Flow func implementation is incorrect, for example, the given inputs do not match.<br>  - The execution of a node times out, causing the data alignment wait to time out. |
| FLOW_FUNC_ERR_TIME_OUT_ERROR = 564001 | NN execution timed out | Check whether there are other errors in the logs that cause model execution to fail. If so, locate the issue based on the actual error. If there is no error log and the model executes normally, adjust the timeout input parameter passed by the fetch data API by increasing its value or directly setting it to -1. |
| FLOW_FUNC_ERR_NOT_SUPPORT = 564002 | Feature not supported | Possible causes are as follows:<br><br>  - The single-func API does not expose this capability. Replacing it with a multi-func API can avoid this error.<br>  - The user has not implemented the corresponding API. For example, in a fault recovery scenario, if ResetFlowFuncState is not implemented, "not supported" is returned by default. |
| FLOW_FUNC_STATUS_REDEPLOYING = 564003 | Degraded deployment in progress | A recoverable error triggers degraded deployment, causing data to be unavailable at present. Other return codes are returned after the degraded deployment is complete. If the degraded deployment succeeds, data is returned normally; if it fails, other unrecoverable error codes are returned. |
| FLOW_FUNC_STATUS_EXIT = 564004 | UDF process exiting | If the process receives an exit signal while the Flow func is waiting for input data, this error code is returned, indicating that the process is about to exit and stops preparing input data. Troubleshoot the cause of the exit signal received by the UDF process based on the logs. |
| FLOW_FUNC_ERR_DRV_ERROR = 564100 | General driver error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| FLOW_FUNC_ERR_MEM_BUF_ERROR = 564101 | Driver memory buffer interface error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the log error reporting, or contact engineers (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| FLOW_FUNC_ERR_QUEUE_ERROR = 564102 | Driver queue interface error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the log error reporting, or contact engineers (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| FLOW_FUNC_ERR_EVENT_ERROR = 564103 | Driver event interface error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the log error reporting, or contact engineers (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| FLOW_FUNC_ERR_USER_DEFINE_START  = 9900000 | User-defined error code, defined starting from this error code | - |
| FLOW_FUNC_ERR_USER_DEFINE_END = 9999999 | User-defined error code, ending with this error code | - |

## AICPU

During model execution, AICPU may report the following error codes to users. The meaning of each error code is described as follows.

| Return Code | Description | Solution |
| --- | --- | --- |
| int32_t AICPU_SCHEDULE_ERROR_PARAMETER_NOT_VALID = 521001 | Invalid parameter validation | This error code is returned when parameter validation fails, including but not limited to input parameters exceeding the system-supported range and mismatched parameters during the process. When this error code is returned, the log prints the abnormal parameters and the cause of the exception. Locate the cause based on the specific logs. |
| int32_t AICPU_SCHEDULE_ERROR_FROM_DRV = 521003 | Driver API returns an error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_NOT_FOUND_LOGICAL_TASK = 521005 | The AICPU task to be executed is not found | Check whether the environment driver package and the CANN package versions are compatible. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_INNER_ERROR = 521008 | AICPU internal error | Check whether the environment driver package and the CANN package versions are compatible. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_OVERFLOW = 521011 | Overflow occurs | An overflow occurs in a multiplication or addition operation. Locate the cause based on the specific logs. |
| int32_t AICPU_SCHEDULE_ERROR_MODEL_EXIT_ERR = 521104 | Model-triggered execution fails | During model execution, the return value is set to an exception flag, so the model cannot continue execution. Check whether there are other errors in the logs, and locate the cause based on the specific logs. |
| int32_t AICPU_SCHEDULE_ERROR_MODEL_EXECUTE_FAILED = 521106 | Model execution failure reported by TSCH during model execution | During model execution, an abnormal termination message is received, and the model needs to be terminated (the termination cause is model stream execution failure). Check whether there are other errors in the logs, and locate the cause based on the specific logs. |
| int32_t AICPU_SCHEDULE_ERROR_TSCH_OTHER_ERROR = 521107 | Other errors reported by TSCH during model execution | During model execution, an abnormal termination message is received, and the model needs to be terminated. Check whether there are other errors in the logs, and locate the cause based on the specific logs. |
| int32_t AICPU_SCHEDULE_ERROR_DISCARD_DATA = 521108 | Mbuf activation is discarded during model execution | During model execution, the cached Mbuf activation exceeds the threshold, and the Mbuf activation needs to be discarded. The solution is to adjust the number of cached Mbufs or the time threshold. |
| int32_t AICPU_SCHEDULE_ERROR_DRV_ERR = 521206 | Driver API returns an error | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_MALLOC_MEM_FAIL_THROUGH_DRV = 521207 | Failed to allocate memory through the driver API | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, check the device memory usage to see whether the device memory limit is reached. Troubleshoot the issue based on the log error reporting, or contact engineers (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_SAFE_FUNCTION_ERR = 521208 | Secure functions such as memcpy_s fail to execute | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_INVALID_EVENT_SUBMIT = 521209 | AICPU fails to submit an event | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support). |
| int32_t AICPU_SCHEDULE_ERROR_CALL_HCCL = 521500 | AICPU fails to call the HCCL API | Check whether the environment driver package is installed properly and whether the device status is normal. If the current environment installation package meets expectations and the environment status is normal, troubleshoot the issue based on the logs, or contact engineers for handling (you can obtain the logs and click [Support](https://www.hiascend.com/support) to contact technical support).|
